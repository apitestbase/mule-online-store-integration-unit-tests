# Online Store — Integration Unit Tests

This repository is an [API Test Base](https://apitestbase.io) workspace containing the Integration Unit Tests for the Online Store MuleSoft APIs, the environments, etc.

It accompanies the article [Integration Unit Testing in Action: MuleSoft](https://apitestbase.io/iut-in-action/mulesoft). Start there.

APIs under test:

- [Create Order API](https://github.com/apitestbase/mule-online-store-create-order-api)

## Prerequisites

- [API Test Base](https://apitestbase.io/docs/quick-start) (desktop app)
- Docker

## Getting the workspace into API Test Base

Clone this repository into API Test Base's `fileplace` folder:

```
cd "<ATB_DATA_DIR>/fileplace"
git clone https://github.com/apitestbase/mule-online-store-integration-unit-tests.git
```

`<ATB_DATA_DIR>` is API Test Base's data directory — see [Administration](https://apitestbase.io/docs/administration) for where it is on your machine.

API Test Base picks up the workspace automatically — it appears in the workspace dropdown list on the UI, with no restart needed.
